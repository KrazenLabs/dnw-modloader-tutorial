# How to write a mod for the DnW Mod Loader

This little tutorial will show you how to create a basic mod.
The example mod here will be called "MoonJump" and will give the player character a low gravity effect.

## Folder structure

First off create a folder somewhere on your system with your mod's name.
> [!IMPORTANT]
> Don't create it inside the game's `Mods` folder. The build process will copy it over later, but you want to keep your dev version somewhere else.

For the sake of this tutorial, we will assume `Documents\DnW Mods\MoonJump`.

The folder will need to contain at least the following three files:

| File | Description |
| --- | --- |
| `MoonJump.csproj` | The **project file**. Needed for the .NET SDK build process. |
| `mod.json` | The **manifest**. Contains your mod's metadata (such as the mod's name, author, etc.). |
| `MoonJumpMod.cs` | The actual **code**. |

## Project file

Create a new file called `MoonJump.csproj` and paste the following content to get a decent starter-build file:

```xml
<Project Sdk="Microsoft.NET.Sdk">

  <!-- The path where the DragNWash.exe is installed. -->
  <PropertyGroup>
    <GameDir>C:\Program Files (x86)\Steam\steamapps\common\Drag'n Wash</GameDir>
  </PropertyGroup>

  <!-- The name of your mod DLL. The mod wil end up in Mods\MoonJump inside the game folder. -->
  <PropertyGroup>
    <AssemblyName>MoonJump</AssemblyName>
    <RootNamespace>MoonJump</RootNamespace>
    <TargetFramework>net472</TargetFramework>
    <LangVersion>latest</LangVersion>
    <AppendTargetFrameworkToOutputPath>false</AppendTargetFrameworkToOutputPath>
  </PropertyGroup>

  <!-- Referenced libraries. Private="false" prevents the SDK from including an extra copy in the final build as these files are already included with the Mod Loader. -->
  <ItemGroup>
    <!-- The mod loader and Harmony -->
    <Reference Include="$(GameDir)\DnWModLoader\DnWModLoader.dll" Private="false" />
    <Reference Include="$(GameDir)\DnWModLoader\0Harmony.dll" Private="false" />
    <!-- The game's own code -->
    <Reference Include="$(GameDir)\DragNWash_Data\Managed\Assembly-CSharp.dll" Private="false" />
    <!-- Unity -->
    <Reference Include="$(GameDir)\DragNWash_Data\Managed\UnityEngine*.dll" Private="false" />
    <Reference Include="$(GameDir)\DragNWash_Data\Managed\Unity.*.dll" Private="false" />
    <Reference Include="$(GameDir)\DragNWash_Data\Managed\netstandard.dll" Private="false" />
  </ItemGroup>

  <!-- Includes mod.json into the build. -->
  <ItemGroup>
    <None Include="mod.json" CopyToOutputDirectory="PreserveNewest" />
  </ItemGroup>

  <!-- Validates the game path is correct and that the loader is installed. -->
  <Target Name="CheckGameDir" BeforeTargets="ResolveAssemblyReferences">
    <Error Condition="!Exists('$(GameDir)\DragNWash_Data\Managed\Assembly-CSharp.dll')" Text="Drag'n Wash was not found in '$(GameDir)'. Open $(MSBuildProjectFile) and set GameDir to your game folder." />
    <Error Condition="!Exists('$(GameDir)\DnWModLoader\DnWModLoader.dll')" Text="The DnW Mod Loader is not installed in '$(GameDir)'. Install it with the DnW Mod Manager first." />
  </Target>

  <!-- Automatically copy the build into the game for easy testing. -->
  <Target Name="CopyToGame" AfterTargets="Build">
    <Copy SourceFiles="$(OutDir)$(AssemblyName).dll;$(OutDir)$(AssemblyName).pdb;$(OutDir)mod.json" DestinationFolder="$(GameDir)\Mods\$(AssemblyName)" />
    <Message Importance="high" Text="Copied $(AssemblyName) to $(GameDir)\Mods\$(AssemblyName)" />
  </Target>

</Project>
```

Make sure to replace the game dir with the correct path for your installation. You should also replace the MoonJump names for assembly and namespace with your own mod name.

## Manifest files

Next create the `mod.json` file:

```json
{
  "id": "yourname.moonjump",
  "name": "Moon Jump",
  "version": "1.0.0",
  "author": "Your Name",
  "description": "Jump much higher! Press J to toggle.",
  "loaderVersion": ">=1.10.0"
}
```

Fill out the fields with your information accordingly.

| Field | Description |
| --- | --- |
| `id` | Your mod's id. Only lower-case letters, digits, `.`, `_` and `-` only. It needs to be unique for your mod. I recommend author.modname or using Unity's package naming standards. **Do not change it once you published your mod**: the mod settings will be saved under this id. |
| `name` | The mod's display name in the loader and manager. |
| `version` | Your mod's version. Use [semantic versioning](https://semver.org/). |
| `author` | Your name :) |
| `description` | A short mod description. |
| `loaderVersion` | Supported loader versions. Again, uses semantic versioning for comparison. |

> [!NOTE]
>If the loader shows your mod as failed with a "mod.json" error, check the JSON formatting (missing commas, etc.).

## Code files

You can use any number of .cs files. The main file (and only the main file) needs a class inheriting from the 'Mod' class.
Let's have a look at an example file for our example mod: `MoonJumpMod.cs`

```csharp
// The Mod class is part of the loader assembly
using DnWModLoader;

// Make sure the root namespace matches the one in your .csproj file.
// Always use a namespace to avoid conflicts with other mods.
namespace MoonJump
{
    // The main class of the mod. It must extend the Mod class.
    public class MoonJumpMod : Mod
    {
        // Runs once on game start.
        public override void OnInitialize()
        {
            Logger.Info("Moon Jump is ready!");
        }
    }
}
```

All this does for now is write "Moon Jump is ready!" into the mod's log.

## Build

You now have the bare minimum needed to build the mod.

To build the mod, go to your terminal and type

```
dotnet build
```

If you did everyting correctly, the log should show something like this:

```
  MoonJump -> C:\Users\you\Documents\DnW Mods\MoonJump\bin\Debug\MoonJump.dll
  Copied MoonJump to D:\SteamLibrary\steamapps\common\Drag'n Wash\Mods\MoonJump

Build succeeded.
    0 Warning(s)
    0 Error(s)
```

## Test ingame

You can now start the game and the new mod should show up in the mod loader menu (and in the manager).

And the log tab should show the message from the mod:

```
[18:08:51.740] [INF] [yourname.moonjump] Moon Jump is ready!
```

The log level and mod id are included automatically by the logger.

Congratulations! This was all you needed for your first mod! The next chapters will go a bit more into the Mod Loader's functionalities and APIs before we add some actual functionality to the mod.
