# Logging

Every DnW Mod Loader mod automatically gets its own `Logger`. Simply call one of the following methods according to the log level you want and provide a string:

```csharp
Logger.Debug("Should only used for debugging during development.");
Logger.Info("Normal info messages, hidden by default.");
Logger.Warning("Recoverable issues, will be highlighted for end users by default.");
Logger.Error("Unrecoverable issues, will be highlighted in the mod manager.");
```

Time, log level and mod id are automatically added to the log:

```
[14:39:24.598] [INF] [yourname.moonjump] Moon Jump is ready!
[14:39:45.078] [DBG] [yourname.moonjump] Jump pressed!
```

> [!WARNING]
> Do not use Unity's default logger (`Debug.Log`). These will go into Unity's player log and will be indistuingishable from logs created by the base game itself. Always use the logger provided to you by the Mod Loader!

The log is shown in the mod loader menu ingame and also written to `Mods\ModLoader.log`. You can also look at the last run log in the Mod Manager.
One previous log file is kept as `Mods\ModLoader.prev.log`.

The loader will also catch any uncaught **exceptions** and log them as errors with a **stack trace**:

```
[14:52:10.301] [ERR] [Loader] Mod yourname.moonjump threw in OnUpdate (1): System.NullReferenceException: Object reference not set to an instance of an object
  at MoonJump.MoonJumpMod.OnUpdate () [0x00012] in C:\Users\you\Documents\DnW Mods\MoonJump\MoonJumpMod.cs:57
  at DnWModLoader.ModLoader.Dispatch (...)
  ...
```

(You should try to avoid these)
> [!NOTE]
> If any of your mod's methods keeps rapidly throwing exceptions (at least 10 within a 10 second window), the loader will automatically disable that method for the rest of the session to prevent the log from getting flooded (the loader will also show this on the mod's card in the loader menu). Fix the issue and then restart the game.

> [!WARNING]
> Since logs are written to disk, avoid logging in methods that are run frequently, such as Update() or OnGUI() to avoid performance impacts.
