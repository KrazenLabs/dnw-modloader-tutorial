# Events

The Mod Loader exposes a bunch of events you can use.

To use an event, override its method in your mod class, for example `OnInitialize`. That method will then be called whenever the event triggers.

## Available event calls

| Method | Called when | Example use cases |
| --- | --- | --- |
| `OnInitialize()` | Called once very early, before the main menu is created | Creating mod settings, preparing things |
| `OnAllModsInitialized()` | Called once after every mod ran its `OnInitialize` | Looking for other mods |
| `OnGameStarted()` | Called once after the main menu has loaded | Anything that need the game to be running |
| `OnSceneLoaded(Scene scene, LoadSceneMode mode)` | Called every time a scene finishes loading | Finding objects in the scene |
| `OnSceneUnloaded(Scene scene)` | Called every time a scene is unloaded | Cleaning up scene objects, states, etc. |
| `OnUpdate()` | Called once every frame, same as Unity's OnUpdate() | Anything that needs to run every frame (animations, etc.) |
| `OnFixedUpdate()` | Called every physics step (default 50 times per second), same as Unity's FixedUpdate() | Physics or other code that should be framerate independent |
| `OnLateUpdate()` | Called every frame after all objects finished `OnUpdate`, same as Unity's OnLateUpdate() | Anything that needs OnUpdate() changes to settle first (for example camera) |
| `OnGUI()` | Called several times per frame for each UI stage | Anything UI related such as drawing text, simple menus, etc. Be conservative with what you do here |
| `OnApplicationQuit()` | Called once when the game is closing | Last-minute saving |
| `OnResourcesChanged()` | Called whenever external mod resources have changed | See [resource folders](resource-folders.md) for more info |

## Call order

```
User starts the game:
  OnInitialize                 once
  OnAllModsInitialized         once
The main menu (StartScene) loads:
  OnSceneLoaded                scene: StartScene
  OnGameStarted                once
After this, for every frame:
  OnUpdate
  OnLateUpdate
  OnGUI                        several times per frame
For every physics step:
  OnFixedUpdate
When starting (or loading) the actual game:
  OnSceneUnloaded              scene: StartScene
  OnSceneLoaded                scene: PlayGame
User closes the game:
  OnApplicationQuit
```

Drag'n Wash has two scenes: `StartScene` is the main menu, `PlayGame` is the actual gameplay scene. Going back to the menu
reloads back to `StartScene`.

## Let's add an event to Moon Jump

Let's log every scene that loads. Override the `OnSceneLoaded` method in your mod class:

```csharp
using DnWModLoader;
// Required for Scene and LoadSceneMode
using UnityEngine.SceneManagement;

namespace MoonJump
{
    public class MoonJumpMod : Mod
    {
        // Runs once, when the game starts.
        public override void OnInitialize()
        {
            Logger.Info("Moon Jump is ready!");
        }

        // Runs every time the game loads a scene.
        public override void OnSceneLoaded(Scene scene, LoadSceneMode mode)
        {
            Logger.Info("Scene loaded: " + scene.name);
        }
    }
}
```

As seen in the event listing, `OnSceneLoaded(Scene scene, LoadSceneMode mode)` gets called with a Scene and a LoadSceneMode. We don't need LoadSceneMode in this case, but the signature still needs to match.

Close the game and rebuild the mod. The log should show something on this on the next run:

```
[14:39:27.616] [INF] [yourname.moonjump] Scene loaded: StartScene
[14:39:36.478] [INF] [yourname.moonjump] Scene loaded: PlayGame
```

## Good to know

**`OnInitialize` runs very early.** The game is not yet finished with its own setup. You should create your mod settings here but game classes and events are not initialized yet, so don't try to subscribe to any of the game's own events here. Do that in `OnGameStarted` or `OnSceneLoaded`.

**Scenes destroy their objects.** When a scene unloads, all objects are removed. If your mod needs an object from the level, look it up again in `OnSceneLoaded`.

**`OnUpdate` runs every frame.** Even while the game is paused.
Keep the code in it short and fast:

- Don't search for objects every frame. Find them once (for example in `OnSceneLoaded`) and save a reference to them.
- Don't log every frame.
- Return early when possible.

**Time between frames.** You can use [Unity's `Time`](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Time.html) class to measure frame timing:

Common examples:

| Method | Description |
| --- | --- |
| `Time.deltaTime` | Time since last frame. |
| `Time.time` | Time since the game started. |
| `Time.unscaledTime` | The same, but it ignores time scale changes (`Time.timeScale`). Useful for profiling your mod. |

Remember to add `using UnityEngine;` to use `Time`.
