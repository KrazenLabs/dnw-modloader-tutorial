# Keys

You can assign actions to hotkeys. You can use keyboard keys, mouse buttons and even gamepad buttons.

## Keyboard

Drag'n Wash uses Unity's **Input System**. You can access keyboard keys through `Keyboard.current` and each key's name:

```csharp
using UnityEngine.InputSystem;

// ...

Keyboard keyboard = Keyboard.current;
if (keyboard.jKey.wasPressedThisFrame)
{
    Logger.Info("J was pressed!");
}
```

You can access the following properties:

| Property | True when |
| --- | --- |
| `wasPressedThisFrame` | The key went down in this frame (true for exactly one frame per press) |
| `isPressed` | The key is currently being held down |
| `wasReleasedThisFrame` | The key was released in this frame |

Because these values are only valid for a single frame, check them in `OnUpdate`.

> [!WARNING]
> Many Unity tutorials use `Input.GetKeyDown(KeyCode.J)`, which refers to Unity's old input system, and it **won't work** in Drag'n Wash.

Instead of `jKey`, you can also look a key up by its **`Key`** value: `keyboard[Key.J]` is the same as `keyboard.jKey`.

`Key` can also be the type of a setting:

```csharp
public ConfigEntry<Key> ToggleKey;

// in OnInitialize:
ToggleKey = Config.Bind("Controls", "ToggleKey", Key.J, "Press this key in the game to switch moon jumping on or off.");
```

This will allow players to rebind that key in the mod config UI.

## Let's add a key to Moon Jump:

```csharp
using DnWModLoader;
using DnWModLoader.Config;
using UnityEngine.InputSystem;
using UnityEngine.SceneManagement;

namespace MoonJump
{
    public class MoonJumpMod : Mod
    {
        // Settings.
        public ConfigEntry<bool> Enabled;
        public ConfigEntry<float> JumpPower;
        public ConfigEntry<Key> ToggleKey;

        public override void OnInitialize()
        {
            Enabled = Config.Bind("Jumping", "Enabled", true, "Turns moon jumping on or off.");
            JumpPower = Config.Bind("Jumping", "JumpPower", 2f, "How strong your jumps are. 1 is a normal jump.", ConfigMeta.Range(1, 3, 0.1));
            ToggleKey = Config.Bind("Controls", "ToggleKey", Key.J, "Press this key in the game to switch moon jumping on or off.");

            Logger.Info("Moon Jump is ready!");
        }

        public override void OnSceneLoaded(Scene scene, LoadSceneMode mode)
        {
            Logger.Info("Scene loaded: " + scene.name);
        }

        public override void OnUpdate()
        {
            Keyboard keyboard = Keyboard.current;
            if (keyboard == null || ToggleKey.Value == Key.None)
                return;

            if (keyboard[ToggleKey.Value].wasPressedThisFrame)
            {
                Enabled.Value = !Enabled.Value;
                Logger.Info("Moon Jump switched " + (Enabled.Value ? "on" : "off"));
            }
        }
    }
}
```

The keyboard null check is important because it not only is null when there is no keyboard at all but also if the player removes the key bind. Without it, a missing key bind would cause a NullReference exception.

> [!NOTE]
> While the mod config UI is open, all key presses are intercepted by the loader. So close the UI before testing the key bind.

## Mouse and gamepad

Using mouse or gamepad buttons works the same as the keyboard:

```csharp
Mouse mouse = Mouse.current;
if (mouse != null && mouse.middleButton.wasPressedThisFrame)
{
    // ...
}

// null when no gamepad is connected!
Gamepad gamepad = Gamepad.current;
if (gamepad != null && gamepad.buttonNorth.wasPressedThisFrame)
{
    // ...
}
```
