# UI

## Drawing with `OnGUI`

You can call Unity's **IMGUI** during OnGUI events. Let's draw some text:

```csharp
public override void OnGUI()
{
    GUI.Label(new Rect(10, 10, 300, 30), "Hello from Moon Jump!");
}
```

> [!IMPORTANT]
> Unity calls `OnGUI` several times per frame: once to plan the layout, once to draw, and once more for every mouse or
> key event. Only draw in `OnGUI`. Change your mod's state in `OnUpdate` and don't log or run expensive code during `OnGUI`.

## Making text bigger: `GUIStyle`

You can use **`GUIStyle`** to format the text.

```csharp
_messageStyle = new GUIStyle(GUI.skin.label);
_messageStyle.fontSize = 32;
_messageStyle.fontStyle = FontStyle.Bold;
_messageStyle.alignment = TextAnchor.MiddleCenter;
```

Note that you can only call `GUI.skin` during `OnGUI`, so you need to create the `GUIStyle` during `OnGUI` once. After that, you can keep it in a field to use elsewhere:

```csharp
if (_messageStyle == null)
{
    // create it (the four lines above)
}
```

Make sure you only create it once and not every frame.

## Other examples

Here are a few other IMGUI methods, in case you want to experiment:

| Method | Draws |
| --- | --- |
| `GUI.Box(rect, "text")` | A box! |
| `GUI.Button(rect, "text")` | A button; it returns `true` while it is clicked. |
| `GUI.HorizontalSlider(rect, value, min, max)` | A slider. Returns the new value. |

Buttons and sliders need a visible mouse cursor to change, which the game only draws in its menus. For anything the player
should be able to change, a setting in the mod config UI window is usually the better choice.

## Let's add some UI text to our mod:

```csharp
using DnWModLoader;
using DnWModLoader.Config;
using UnityEngine;
using UnityEngine.InputSystem;
using UnityEngine.SceneManagement;

namespace MoonJump
{
    public class MoonJumpMod : Mod
    {
        // Settings
        public ConfigEntry<bool> Enabled;
        public ConfigEntry<float> JumpPower;
        public ConfigEntry<Key> ToggleKey;

        // How long the message stays on screen
        private float _messageUntil;
        private GUIStyle _messageStyle;

        // Runs once, when the game starts.
        public override void OnInitialize()
        {
            Enabled = Config.Bind("Jumping", "Enabled", true, "Turns moon jumping on or off.");
            JumpPower = Config.Bind("Jumping", "JumpPower", 2f, "How strong your jumps are. 1 is a normal jump.", ConfigMeta.Range(1, 3, 0.1));
            ToggleKey = Config.Bind("Controls", "ToggleKey", Key.J, "Press this key in the game to switch moon jumping on or off.");

            Logger.Info("Moon Jump is ready!");
        }

        public override void OnSceneLoaded(Scene scene, LoadSceneMode mode)
        {
            Logger.Info("Scene loaded: " + scene.name);
        }

        public override void OnUpdate()
        {
            Keyboard keyboard = Keyboard.current;
            if (keyboard == null || ToggleKey.Value == Key.None)
                return;

            if (keyboard[ToggleKey.Value].wasPressedThisFrame)
            {
                Enabled.Value = !Enabled.Value;
                _messageUntil = Time.unscaledTime + 2f;
                Logger.Info("Moon Jump switched " + (Enabled.Value ? "on" : "off"));
            }
        }

        public override void OnGUI()
        {
            if (Time.unscaledTime > _messageUntil)
                return;

            if (_messageStyle == null)
            {
                _messageStyle = new GUIStyle(GUI.skin.label);
                _messageStyle.fontSize = 32;
                _messageStyle.fontStyle = FontStyle.Bold;
                _messageStyle.alignment = TextAnchor.MiddleCenter;
            }

            string text = Enabled.Value ? "Moon Jump: ON" : "Moon Jump: OFF";

            // Draw the text twice: a black copy a little lower and to the right as a shadow,
            // then the white text on top of it.
            GUI.color = Color.black;
            GUI.Label(new Rect(2, 62, Screen.width, 50), text, _messageStyle);
            GUI.color = Color.white;
            GUI.Label(new Rect(0, 60, Screen.width, 50), text, _messageStyle);
        }
    }
}
```
